# MiniBank — Java Banking System

A console-based banking application developed using Java to demonstrate Object-Oriented Programming concepts.

## Features
- Open and manage bank accounts
- Deposit, withdraw, and transfer money
- View accounts and transaction history
- Generate end-of-day reports
- Save and load account data
- Handle banking errors using custom exceptions
- Demonstrate collections, generics, and multithreading

## Technologies
- Java
- VS Code
- Java Collections Framework
- File Handling and Serialization
- Multithreading

## Project Structure

- `model/` — Account classes, interfaces, and annotations
- `service/` — Banking operations and concurrency
- `util/` — Storage, logging, repositories, and reports
- `exception/` — Custom exceptions
- `MiniBank.java` — Main application
